# 校味项目说明

## 产品定位

校味是一款校园美食点评、反馈与打卡工具，主要帮助同学决定每天想吃什么。先让美食信息容易找到，再通过具体评价和个人偏好辅助选择。

## 功能结构

| 入口 | 核心内容 | 辅助内容 |
| --- | --- | --- |
| 首页 | 普通搜索、八类美食图标、推荐菜品、新菜与评价 | 今天吃什么、人流参考、随机挑一顿 |
| 美食地图 | 校园点位、食堂楼层、档口、菜单与具体评价 | 档口排队、食堂留言 |
| 打卡动态 | 美食打卡、实拍、感受、对应菜品 | 我的打卡筛选 |
| 我的 | 口味与近期习惯、自己的打卡和点评、收藏 | 预约／送寝订单、食堂留言、记录同步 |
| 商家工作台 | 菜品管理、上新、订单处理、点评与留言 | 营业信息、排队人数、等待时长、送寝开关 |

## 登录与身份

首次进入选择“我是学生”或“我是商家”。学生填写体验昵称；商家选择经营档口。身份用于交互模拟，不要求填写真实账号密码。退出身份后回到登录页重新选择，当前记录会保留。

云端身份由部署平台提供，每个平台账号有独立体验空间。模拟学生与商家角色共享该空间，用来演示双端联动；当前没有真实校园用户或真实商家权限。

## 首页内容优先级

搜索 → 分类 → 推荐美食。分类包含食堂美食、面食粉面、轻食、咖啡、奶茶饮品、早餐、甜品小吃和超市。

每道菜展示名称、价格、食堂／楼层／档口、评分与点评人数、口味标签、模拟等待时间及具体评价。详情页才展开点评、打卡、预约、收藏与位置入口。

## 三层美食导航

校园示意地图中可以点选梧桐苑、稻香苑、模拟咖啡点和模拟超市。

食堂层显示楼层切换和档口平面示意；点选某个档口后，展示该档口菜单与排队情况；点开菜品则进入价格、评价和预约详情。

梧桐苑和稻香苑名称参考[校方2025年餐饮指南](https://hqfw.sicau.edu.cn/info/1019/1552.htm)。点位、内部布局及模拟服务状态均非实测。稻香苑当时暂停营业，当前状态未核实，页面中有明确提示。

## 点评、打卡与反馈

点评记录评分、口味／分量／性价比等标签、文字和可选实拍；可以同时保存为打卡。打卡也可以独立发布，关联具体菜品。

食堂留言按“想吃的新菜、口味与分量、排队与服务、其他建议”分类；对应食堂的商家模拟身份可以回复。菜品点评由对应档口回应。

## 用餐助手与个人偏好

用餐助手是次级工具，支持输入简单自然语言，例如“2个人，人均15元，想吃清淡不辣的午饭”。它也提供人数、预算、口味和饮食目标的结构化选项。

推荐先过滤营业、在售、预算和忌口，再匹配显式口味与目标，并参考收藏、本人高分点评、打卡和近期饮食习惯。输出每人的菜品建议、合计价格及其他选择。此功能是可解释规则演示，尚未调用大模型。

个人档案保留均衡／减脂／增肌目标、喜欢的口味、近期习惯、日常预算和不想吃的食材。

## 预约与商家流程

学生选择菜品 → 自取或送寝 → 份数、时段、寝室、备注 → 确认模拟预约。

商家处理：待接单 → 制作中 → 待取餐／配送中 → 已完成。学生只能取消尚未接单的预约；送寝只对开启此服务的档口提供。无真实付款或履约。

商家发布、编辑与下架菜品后，学生菜单同步变化。排队人数和等待时长由商家手动维护，当前展示为模拟值，不是传感器监测。

## 状态设计

无搜索结果、无打卡、无点评、暂无订单、闭店和下架、预算或忌口筛选无匹配、未同步记录、云端冲突均有对应提示。恢复示例数据前需要确认。
