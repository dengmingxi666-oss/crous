# 校味 · 校园美食点评推荐

校味帮助同学发现食堂好味道、查看真实感受、打卡记录和反馈建议，轻松决定每天想吃什么。

**[在线版本](https://campus-flavors.dengmxi.chatgpt.site)** · **[项目说明](docs/PRODUCT.md)** · **[技术路线](docs/TECHNICAL.md)** · **[验证记录](docs/VALIDATION.md)** · **[单文件体验版](standalone/xiaowei-demo.html)**

## 这次重构

- 使用正常的校园美食产品用词，品牌改为“校味”。
- 登录页选择学生或商家模拟身份，页面顶部不再承担身份切换。
- 学生主导航为：首页、美食地图、打卡动态、我的。
- 首页依次展示普通搜索、食堂美食／咖啡等八类图标和推荐菜品。
- 用餐助手、随机转盘、留言和预约放在辅助入口或“我的”。
- 商家端独立管理选中的档口：菜单、上新、订单、点评与留言、营业与排队设置。

## 体验路线

1. 登录页选择学生，填写体验昵称。
2. 在首页搜索菜品、档口或食堂，切换咖啡、轻食等分类，打开菜品详情。
3. 点击“写点评”或“打卡”，填写具体感受，可上传实拍；在打卡动态或我的页面查看。
4. 打开美食地图：校园点位 → 食堂楼层 → 档口 → 菜品。每个档口展示模拟排队和等待时间。
5. 需要灵感时，打开“今天吃什么”，输入人数、预算和口味；或在辅助工具中使用转盘。
6. 预约一份自取或送寝订单，退出当前模拟身份，选择对应档口的商家身份，依次接单、制作、取餐或配送。
7. 商家上新菜品、修改排队状态、回复点评或食堂留言后，学生端可查看变化。

## 川农成都校区地图范例

食堂名称参考[校方餐饮服务指南](https://hqfw.sicau.edu.cn/info/1019/1552.htm)中的梧桐苑、稻香苑。2025年资料曾标注稻香苑暂停营业，当前状态未核实。

地图点位、食堂内部平面、档口、咖啡与超市位置、菜品和人流均为模拟，不能用于精确校园导航。地图在产品中明确标注了这些范围。

## 本地运行

需要 Node.js 22.13+ 和 pnpm。

```bash
pnpm install
pnpm dev
pnpm test
pnpm typecheck
pnpm build
```

直接打开 `standalone/xiaowei-demo.html` 也可以体验本机版本。重新生成它与 Pages 文件：

```bash
pnpm demo:build
```
