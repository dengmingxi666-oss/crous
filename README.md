# CROUS · 食物法庭

> 好吃判「夯爆了」，踩雷留下具体证词。让校园每一顿都有好选择。

**[在线体验](https://crous-food-court.dengmxi.chatgpt.site)** · **[项目说明](docs/PRODUCT.md)** · **[技术路线](docs/TECHNICAL.md)** · **[验证记录](docs/VALIDATION.md)**

CROUS 是围绕校园食堂设计的双端交互 MVP。学生可以设置口味、发现新菜、查看点评、随机抽取菜品或窗口、预约自取及模拟送寝；商家可以维护窗口、上新菜品、回复点评、处理预约和更新排队状态。

在线版本使用 ChatGPT 登录与当前账号独立的数据空间。右上角切换学生端／商家端即可体验，两端共享当前账号的数据；导航和弹窗中的功能均可操作。首次打开可点“体验路线”。

## 功能

| 学生端 | 商家端 |
| --- | --- |
| 今日首选、偏好推荐、新菜尝鲜 | 经营概览、在售菜单与待处理预约 |
| 菜品／窗口转盘、预算和忌口筛选 | 菜品发布、编辑、上架与下架 |
| 评分、分量与性价比标签、实拍图、商家回应 | 回复学生评价、回应想吃投票 |
| 食堂、楼层、窗口位置与排队状态 | 店铺资料、营业时间、公告与排队维护 |
| 预约自取、送餐到寝、订单进度 | 接单→制作→待取餐／配送→完成 |
| 收藏、分享、口味与均衡／减脂／增肌偏好 | 选取不同窗口进行管理 |

## 5分钟体验

1. 学生端进入「口味档案」，选择减脂、清淡和预算，返回「今日开庭」查看推荐变化。
2. 点击「今天吃什么」，在菜品和窗口转盘间切换，随机挑选合适的一顿。
3. 打开菜品详情，查看美食证词，预约自取或送寝。送寝需填写示例寝室地址。
4. 切换商家端，在「订单预约」选择订单对应的窗口，依次接单、制作、通知取餐或模拟配送。
5. 返回学生端「我的订单」查看状态；完成后提交评价和实拍图，再切商家端回复。
6. 商家发布一款新菜或修改排队时长，学生端的菜单、新品区和窗口状态随之更新。

## 风格

奶油纸张、墨绿文字与判词橙构成轻松的校园“食物法庭”。“新菜上庭”“申请复吃”“分量正义”等表达服务于明确的功能。评分和点评仍保留具体描述，帮助同学按自己的口味判断。

## 本地运行

需要 Node.js 22.13+ 和 pnpm。仓库保留锁文件。

```bash
pnpm install
pnpm dev
```

静态交互也可以单独体验：

```bash
python -m http.server 8080 --directory public/app
```

访问 `http://localhost:8080`，进入本机保存模式。框架开发模式默认沿用部署环境的身份策略；无有效身份时可直接访问 `/app/index.html` 体验静态交互。

```bash
pnpm test
pnpm typecheck
pnpm build
```

## 当前范围

- 菜品、窗口、评分与排队人数均为校园示范数据，菜品图是 SVG 插画。
- 云端保存真实实现；每个登录账号拥有独立体验空间，同一账号可在不同设备继续。
- 学生／商家角色切换用于体验，不构成真实商家权限管理。
- 预约、送寝与订单状态是可操作的模拟流程，无真实支付、配送或校园运营接入。
- 浏览器端交互与业务模型已检查；当前执行环境未提供浏览器控制，尚未完成真实浏览器视觉验收。
